Licenses

What Tracelucid is offered under, and the open-source software it includes.

Tracelucid

Tracelucid is free to use. Its source code is not public.

Not included: Wireshark and Npcap

Tracelucid reads packets with Wireshark's tools (tshark, dumpcap) and, on Windows, Npcap for live capture. They are not part of the Tracelucid installers: you install them yourself, Tracelucid runs them as separate programs, and they keep their own licenses (Wireshark: GPL-2.0-or-later; Npcap: its own license).

Third-party software in Tracelucid

The installers include open-source components under their own licenses (MIT, BSD, Apache-2.0, MPL-2.0 and others). Each notices file lists every component in that build with its version and license, followed by the full license texts.

v0.4.0Notices
WindowsWindows notices — 231 components, for the .exe and .msi installers
LinuxLinux notices — 263 components, for the .deb, .rpm and .AppImage installers

The lists differ because each operating system's build bundles different libraries: the Python runtime and native libraries in the analysis engine, and the Rust crates in the app.

Linux AppImage: the system libraries packed inside it (GTK, WebKitGTK and others) carry their copyright files in usr/share/doc inside the AppImage. Their source code is available from the Debian/Kali source packages of the same name and version.

Components under the Mozilla Public License 2.0 are used unmodified; their source code is available from crates.io under the name and version listed.
